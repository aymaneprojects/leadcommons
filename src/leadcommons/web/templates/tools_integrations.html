{{ tic("webhook") }} Outgoing webhooks

LeadCommons sends a JSON POST to your URL when an event happens. Each request carries X-LeadCommons-Event and X-LeadCommons-Signature: sha256=…, an HMAC-SHA256 of the body made with the hook's secret.

{{ tic("sparkles") }} MCP: use LeadCommons from Claude or ChatGPT

The MCP server lets an AI assistant search companies, find people and build lists in your own database.

Claude Code

claude mcp add leadcommons -- leadcommons mcp

Claude Desktop

{
  "mcpServers": {
    "leadcommons": { "command": "leadcommons", "args": ["mcp"] }
  }
}

ChatGPT and other remote clients

Run leadcommons mcp --http behind HTTPS and give the client a bearer token: set LEADCOMMONS_MCP_TOKEN{% if tokens %}, or use one of your {{ tokens }} API token{{ "s" if tokens != 1 }}{% endif %}.

{{ tic("terminal") }} REST API

Everything the app does is available as JSON under /api. Create a token and send it as a bearer token.

curl -H "Authorization: Bearer lc_…" {{ base }}/api/companies?q=software
