# v0.3 contracts between features

Every page follows the founder's Apollo screenshots for layout and interaction, in the
LeadCommons dark/orange theme, with our own wording, logo and icons. Every POST checks the
Origin/Referer like `pages.csrf`. Demo mode (`settings.mode == "demo"`) never sends email,
never crawls and never calls an LLM; writes are allowed (temporary database).

## Shared Python
- `leadcommons.store.Store.engine` — engine for feature repositories (tables on `store.tables.Base`).
- `leadcommons.store.pipeline.ActivityRepo(engine).add(kind, summary, *, person_id, company_id, deal_id, meta)`
  and `.list_for(...)` — the activity timeline. Kinds: note, call, meeting, email_sent,
  email_reply, task, task_done, deal, deal_stage, sequence, workflow.
- `leadcommons.workflows.emit(event, **payload)` — see its docstring for events.

## HTML endpoints each feature provides (HTMX partials return a <dialog> or a fragment)
| Provider | Endpoint | Used by |
| --- | --- | --- |
| engage | `GET /partials/sequence-picker?ids=<person ids, comma>` + `POST /sequences/enroll` (sequence_id, ids) | search row/bulk actions, person page |
| engage | `GET /partials/task-new?person_id=&company_id=&deal_id=` + `POST /tasks` | search, person/company pages, deals |
| engage | `GET /partials/email-compose?person_id=` + `POST /emails/send` | search row actions, person page |
| pipeline | `GET /partials/activity?person_id=&company_id=&deal_id=` (timeline fragment) | person/company pages, deals |
| pipeline | `GET /partials/deal-new?company_id=&person_id=` + `POST /deals` | company/person pages |
| pipeline | `GET /partials/note-new?...` + `POST /notes`; `GET /partials/call-log?person_id=` + `POST /calls`; `GET /partials/meeting-new?...` + `POST /meetings` | person/company pages |
| insights | `GET /partials/insights?company_id=&tab=overview|technologies|jobs|funding|contact` | company drawer/page, person page |
| insights | job kind `company_insights` {company_id, domain}; `GET /api/companies/{id}/insights` | company pages, workflows |
| tools | `GET /workflows/new?source=<companies|people>&query=<qs>` | search "Create workflow" menu |

## Sidebar (owned by tools)
Home, AI Assistant · Prospect and enrich: People, Companies, Lists, Data enrichment ·
Engage: Sequences, Emails, Calls, Tasks · Win deals: Meetings, Conversations, Deals ·
Tools and automation: Workflows, Analytics, Integrations · footer: Onboarding hub,
Email setup and health, Settings.

## Settings menu (owned by tools; sections provided by others)
Workspace overview, Data packs, Email verification & health, Privacy & opt-out, Account,
About (existing) + Mailboxes `/settings/mailboxes` and Sending `/settings/sending` (engage),
Deal stages `/settings/deal-stages` (pipeline), API tokens `/settings/api`, Integrations
`/settings/integrations` (tools).
